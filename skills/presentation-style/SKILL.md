# Presentation writing style

- Never use semicolons in visible slide text. Split the sentence, use a comma where appropriate, or use separate bullets instead.
- This punctuation rule applies to slide titles, bullets, captions, tables, and speaker notes. Preserve semicolons required by code or drawing syntax when they are not visible prose.
