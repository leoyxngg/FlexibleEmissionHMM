Before benchmarking the HMM with different emission models, we run the vanilla HMM (Gaussian emission) with [2, 3, 4] of regimes. We used LR test to determine which model should be selected for our sp500. See [[]]the notebook at notebooks/sp500_lr_test.ipynb. We also ran the experiment for the gaussian 2 regimes HMM with different number of rolling parameter as an initial aid (defined a function to rank the score of being a higher volatility regime) to the HMM model, but the model is only fitted on the log return(notebooks/sp500_two_regime_experiment.ipynb). However, it seems like different initial parameters do not affect the model training afterward, it converges to the same model. We also ran the experiment for the vanilla HMM with rolling parameters (notebooks/sp500_two_regime_rolling_emissions.ipynb). Based on the AIC and BIC, 60 rolling parameters(volatility and mean) are better input for the model. In the future, we will code them in a more systematic way, so we can compare different settings of HMM.
